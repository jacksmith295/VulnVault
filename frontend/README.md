# VulnVault application

The Next.js application contains the UI and server-side application logic. Follow the [root setup guide](../README.md) for PostgreSQL, development email, configuration, migrations, and verification commands.

From this directory, `npm run dev` starts local development. Authentication uses the application's `/api/auth` routes; credentials and database access remain server-side. Workspace onboarding and vulnerability tracking are subsequent implementation slices.
